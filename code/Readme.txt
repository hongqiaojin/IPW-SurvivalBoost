# An Inverse Probability Weighted SurvivalBoost Method for Right-Censored Case-Cohort Studies

The accompanying `.R` file contains the core R implementation of the inverse probability weighted SurvivalBoost method described in the paper.

## Simulation studies

See the paper’s simulation study section for the data-generating mechanisms, parameter settings, and evaluation criteria. To reproduce a simulation scenario, configure it in R using the settings reported in the paper and use the accompanying `.R` file to fit the proposed method.
